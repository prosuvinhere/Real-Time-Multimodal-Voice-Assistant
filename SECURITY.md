# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our real-time voice infrastructure seriously.

If you believe you have discovered a vulnerability, please DO NOT open a public GitHub issue. Instead, report it privately via email to the maintainers or via GitHub's Private Vulnerability Reporting feature.

Please include:
- A description of the issue and potential impact
- Detailed reproduction steps or a minimal proof of concept
- Any potential remediations or mitigations you have identified

You will receive an initial response within 48 hours acknowledging receipt of your report.
